# 教师首轮验证后的改进判断

本轮只复用已保存的官方valid预测做CPU分析，并查阅原始论文。第二步OOF与学生训练暂缓；没有新训练、原图模型推理、GPU工作或test数据分析。

## 阶段验收约定

按用户最新要求，每个大阶段结束后先核验完整性，再比较Macro-AUC、十类AUC、患者级不确定性、误差切片及资源成本，反馈保持或修改的理由，再确定下一阶段。已有命令是入口，不代表跳过复盘自动推进。

## 已有结果和新诊断

- 五教师identity 0.801639，双视图0.802467，差0.000828。228患者聚类配对bootstrap1000次的95%区间[-0.001788,+0.003106]跨0，不能认定稳定增益。
- 类别1仅24个阳性Study/16患者，类别2为37/13。十类同等计入Macro-AUC，弱类值得研究，少量阳性也使单次valid选择易波动。
- 逐类在整份valid挑原图/翻转/均值得0.803133，但按患者5折交叉选择、10种划分的平均0.800044，低于固定均值0.802467。该交叉拟合只是选策略的稳定性诊断，不是新的独立测试集。
- 删除单教师分数最弱的fold0后为0.802303，略低于全5；删fold3得0.803987，但同valid探索有选择偏差，配对区间也跨0。不能只按单教师AUC删模型。
- 现有Study概率上的logit平均0.799407、rank均值0.799878、中位数0.800641，均低于概率平均。测试集跨样本排名不能直接照搬为推理策略。
- 用训练pos_weight在Study平均之后做近似先验修正再平均为0.803356；该增益区间跨0，且非精确逐图校正，只作为新验证候选。学生已有的逐视图logit对齐仍应保留。
- fold0同折E13为0.781233，E20为0.771345；类别1从0.598054降至0.550524，提示训练后期泛化变差。它不证明所有教师都应改成13轮。
- 原图单教师预测有少量同分，但无严重0/1饱和；BF16精度不像主要瓶颈，不优先为精度差异重跑全部验证。
- 单图Study和多图Study的AUC差距很大，但病谱也不同，不能据此断言模糊、早期病变或分辨率是原因。

## 教师侧建议

1. 保留现有教师和基准。最值得补的GPU实验是fold0的E13 EMA原图+翻转验证，与已存在的E20和五教师结果比较；不原样重复五教师验证，也不立刻重训五折。
2. E13并非官方禁止使用。官方valid没有加入训练，可以用于选择检查点；当前限制来自本项目“固定轮数最终EMA”协议。若决定采用E13，须正式建立新选择协议与集合、记录真实epoch/来源/选择依据，保留原始E20声明，不能修改旧完成标志或靠外折标签挑epoch。现有缓存校验器不能直接偷换文件。
3. 补充验证时保存逐图、逐视图原始logits，而不只保存Study平均概率。先用训练得到的pos_weight做逐图精确的候选先验修正，再做TTA与Study汇总；这样以后比较校准、汇总等方法可以复用logits，避免反复GPU推理。
4. 若需要新教师，先小规模验证一个外折的第二seed或经许可核验的异构ImageNet教师。每张train若要真正多教师严格OOF，所有参与教师都必须排除该患者；两位/折意味着10个教师，不是直接把现在五教师平均预测train。
5. 再训练时优先检查过拟合与弱类目标，例如只改变一种正样本权重强度或采用规范的训练内层选epoch流程，不按外折选模。若教师更换为ASL等不同损失，不能机械沿用加权BCE推导的logit先验修正。

这些是研究建议，尚未重训、改教师或升级缓存协议。

## 学生侧优先级

先补同分辨率、同seed的纯监督BCE对照（α=0），再比较现有α=.2/T=2蒸馏。两者保持数据、有效batch、增强、EMA和验证TTA一致，确认KD本身有益，再做512/768和多seed组合。五教师集成0.802467不能当作每张OOF软标签质量或学生保底成绩。

之后可分别研究较温和的类别加权、ASL或AUC导向微调，每次改一个因素。ASL论文主要展示mAP，不等于本任务Macro-AUC保证提升；AUC margin需要专门优化与正负样本处理，不直接塞进现有BCE+KL相加。

学生有多个合格模型后，可研究同架构、同预训练初始化、相近微调轨迹的权重平均。它可能降低部署成本，但和预测概率集成不同，不能保证等效；当前EMA也已经是沿轨迹的平均。不同外折教师直接做权重平均后预测train，会破坏严格OOF，不能用于此处偷省教师数。

## 原始资料及适用边界

- [On the Efficacy of Knowledge Distillation, ICCV2019](https://arxiv.org/abs/1910.01348)：更大或更准的教师不一定更利于蒸馏，早期教师检查点可改善部分设置。支持做对照，不证明本任务某个epoch必胜。
- [Better Aggregation in Test-Time Augmentation, ICCV2021](https://arxiv.org/abs/2011.11156)：TTA可能同时修正和破坏预测，简单平均也非普遍最优。不能因此在小valid上无约束搜逐类权重。
- [BCEWithLogitsLoss, PyTorch2.10官方文档](https://docs.pytorch.org/docs/2.10/generated/torch.nn.BCEWithLogitsLoss.html)：明确正样本加权的目标。按其风险公式推导，理想充分拟合时logit(q)=logit(真实条件概率)+log(w)，真实模型校正仍只是可检验近似。
- [Asymmetric Loss for Multi-Label Classification, ICCV2021](https://arxiv.org/abs/2009.14119)：正负不平衡处理及mAP实验，作为单独候选。
- [Large-scale Robust Deep AUC Maximization, ICCV2021](https://arxiv.org/abs/2012.03173)：AUC margin的原始研究，医学分类实验证据可供参考；只借方法，不使用论文外部医学数据或其训练权重。
- [Model soups, ICML2022](https://proceedings.mlr.press/v162/wortsman22a.html)：微调模型权重平均的研究；用于未来合格学生的候选，不能承诺等同预测集成。
