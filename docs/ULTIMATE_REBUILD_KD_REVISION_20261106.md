## 1. 修正结论

**我改变上一版的优先级：异构大教师集成 → Study级知识蒸馏 → 两个中等规模异构学生 → 全量训练后固定集成，作为主线。直接W8大模型保留为竞争基准及后备。**

上一版主要从“保留大模型容量、避免蒸馏损失”推导直接部署优先，没有足够重视本项目的蒸馏证据与教师规模不受500MB限制的空间。量化主要解决部署体积；蒸馏还可能把不同架构、尺度和视角的判断转移给学生，并通过软目标影响学习。后者更值得优先验证，但它不会自动修正教师的共同错误，也不保证学生优于直接大模型。

## 3. 教师应该比最终模型更强、更丰富

主教师采用两个不同家族：

- **DINOv3 ViT-L/16**：通用图像初始化，完整Study监督，从512到768全图，学习全局结构和空间token表征。公开来源、许可与固定revision沿用上一版已核验记录。
- **ConvNeXt V1-Large，ImageNet22K来源**：高分辨率卷积教师，重点保留局部纹理、边缘及细小征象；使用已核验的Apache-2.0公开自然图像权重。与ViT同时按相同Study标签训练，检验真实互补性。

教师在最终推理中不加载，允许其总资产超过500MB。多尺度与固定TTA可以在离线产生软目标时使用；每一项的收益仍须在相同患者验证范围确认。

H+约840M参数，可作为一次替代L的匹配挑战者；7B约6.716B参数只列后续受限挑战，不默认训练。已匿名读取timm对应API确认其元数据公开、非gated、LVD-1689M来源及DINOv3许可标记，但这不替代实际权重/许可归档与最终赛事核验。更大的通用编码器能否成为更好的胸片教师，要由任务结果决定，不能只按参数数指定胜者。

官方train自监督仍是受限对照，只有教师本身或其学生在外层确认集上获益才扩大。它不与换H+、新损失、采样及多个蒸馏目标同时默认叠加。

## 4. 学生规模和蒸馏目标

首选两个学生：**ViT-Base + ConvNeXt-Base**，分别从合规通用权重初始化。FP16纯权重约173MB + 175MB，约350MB，配套文件仍有余量。第三个新raw Tiny只在可复验的额外集成收益成立时加入，总体预计约405～415MB；500MB按实际加载权重及全部必要配套资产验收。

不把Tiny的历史最好成绩理解为今后只能用Tiny，也不预设三个学生一定优于两个。学生架构应提供不同的误差模式；若一个教师/学生只增加相关误差，就删除该成员。

蒸馏首先只改变软监督：

1. **硬目标**：全部原始十类Study标签，多标签BCE；不删除图像、不修改标签，不把未列类别当未知。
2. **软目标**：由排除该患者的ViT教师和CNN教师，对完整Study、固定多尺度/TTA得到的十类连续输出。教师起始采用统一等权，强度与互补性成立后才保留；类别权重引起的logit偏移须明确对齐，不能机械平均不同目标尺度。
3. **损失**：硬标签为主，逐类sigmoid/Bernoulli KD为辅，包含正负两项。起始alpha=0.2、温度T=2作为历史可解释锚点，前两轮渐进启用；筛选结束后固定。十类疾病并不互斥，禁止使用十类softmax KL。
4. **比较顺序**：先检验“同一学生纯BCE vs 同一学生加Study级KD”。空间特征/关系蒸馏只在logit KD成立后增加一个独立对照；几何位置、视角、尺度必须可对齐，不默认强迫ViT和CNN逐位置完全一致。

所有教师、学生都接收完整Study视图；不能用只出现在某个侧位/裁块的Study阳性，强制要求每个局部都是阳性。低confidence或教师分歧仅作诊断，初版不因置信度阈值改写/删去困难真实标签。

## 5. 评估必须隔离整个教师—学生链路

重新验证学生时，最容易犯的错误是：先在全train生成五折教师OOF缓存，再对学生做train内部五折验证。虽然每个训练样本的软标签是自身折外，生成学生训练软标签的教师仍可能见过学生验证患者。此时外层验证并不干净。

采用以下明确协议：

- 在原始train患者上冻结一个外层划分，记训练部分为R、确认部分为H。历史数据已被多次研究过，H只能称新协议下冻结的患者确认集，不能称从未接触的隐藏测试。
- **H患者不参加任何教师训练、自监督、软标签拟合或学生训练。** 所有选择预先固定或在R内部额外患者开发范围完成。H只对固定日程最终EMA做末次配对评估，不用来早停、挑checkpoint、调温度/alpha或融合；用过H筛选后，后续复验必须冻结配方并另做外层划分。
- R内部做3折患者OOF教师，每折两个家族，共6个教师。R中某个Study的软目标只用排除它的对应ViT/CNN两个教师；不能把其余见过该患者的教师也平均进来。3折教师各训练R的2/3，训练量及其对软目标强度的影响如实记录。
- 学生在R的全部原图上训练，在H上验证。相同学生的BCE和KD版本保持初始化、seed、图像覆盖、分辨率、有效batch、日程、EMA和TTA一致，隔离KD贡献。H上的教师集成表现也保存，但它与R中每样本仅两个折外教师的软目标不是同一集成，不能混称。
- 有希望后做第二个完整外层复验，冻结所有选项；不默认5外折×5内折×多家族的无界嵌套。最终若要声称学生严格五折OOF，则必须为每个外折重建其教师链路，不能靠换名称规避。

教师在R上训练后直接教R，是合法的标准KD，并不必然泄漏H。若用这种更便宜的训练内目标做先导试验，必须明确标为in-sample teacher KD；它不能冒充本方案的严格OOF软目标，也不能替代OOF路线的最终检验。

## 6. 真正决定胜负的比较

在同一个外层患者H上，比较：

| 候选 | 目的 |
|---|---|
| 同一Base学生，纯BCE | 确认学生本身的基准 |
| 同一Base学生，BCE + 新Study KD | 衡量蒸馏本身的增量 |
| 两个不同家族的KD学生固定集成 | 检验最终部署组合的互补 |
| 真实W8大ViT + CNN-Base/Tiny或经验证的量化CNN | 保留上一方案作为强竞争基准；FP16 CNN-Large教师不直接装入该组合 |

直接部署对照也必须排除H，并尽量匹配学生R的训练覆盖；若需要训练完整R的大教师，须另计run和预算，不能把仅训练R的2/3的内层教师当作同覆盖对照。若两条路线使用了不同训练覆盖，必须披露，不按其差值归因蒸馏。

主指标继续为Study十类Macro-AUC，报告患者簇配对区间、逐类、AP/单图/反复检查等固定切片。需要回答三个问题：教师判断是否更好，学生是否从教师受益，最终学生组合是否优于同覆盖的直接大模型。教师loss下降、学生更小、或某一个valid点分上涨，都不能替代这些证据。

如果KD没有增益，或教师在弱类/困难场景的共同错误被传给学生，就退回直接部署路线。蒸馏的主线地位表示优先投入验证，不表示事先指定它必须胜出。

## 7. 最终重训及预算修正

验证通过后，冻结教师、学生、日程、软目标、TTA、融合及所有选择，再决定把官方valid并入最终训练。train+valid共31,766图/19,372 Study；此后不再用原valid挑epoch、学生或融合。

在全部允许训练数据内部重建3～5折教师OOF软目标，训练最终两个学生。五折两家族共10个教师，但每个训练Study实际接受的是对应排除它的两个教师，不是全部10个。离线教师只随材料申报来源、SHA、许可、脚本及关系，不参与最终推理体积。

旧方案的400～700 GPU小时不能原样当作本路线承诺：增加了CNN-Large、内层教师和学生对照，量级可能更高。首个正式授权应限定为**一套外层隔离的教师/学生验证**，逐项列出6个内层教师、学生BCE/KD及必要直接部署对照的实际预算；短探针后再核定。第二外层复验、最终全量教师和学生均按阶段释放预算，不同时默认开展H+、7B、五折SSL、多个feature loss及多种量化。

最终CSV由实际选定的学生或量化模型及共享predict/cost链路生成；保留76.92最佳提交。研究阶段暂不考虑推理时延，最终仍须满足规则的500MB、Study时延和一致性要求。cost样例不完整，不用于调策略。
