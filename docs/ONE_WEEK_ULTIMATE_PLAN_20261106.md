2026-11-06，香港时间。用户本次明确要求全盘接管、制定方案后立即训练，允许新学生，禁止重新训练教师。本方案在该授权内执行；旧KD/clean/raw队列及STOP保持原状，独立新建`ONE_WEEK_20261106`。本页是训练前冻结的决定，实际执行以新运行状态和优化器计数为准。

**最有希望的新增候选是：从冠军Tiny768/P2配方出发，用全部官方原始train与官方valid的有标签病例重新拟合学生，固定第9轮EMA；另训一个seed作为预先登记的等权平均备选。现有教师完全冻结，不再花一周训练教师。**

这不是承诺突破76.92。原始train补回16图本身只增加0.053%图片；真正有意义的变化是完整训练覆盖、增加859个已有标签Study，以及减少小valid上的反复选择。若无新增可靠证据，76.92继续是实际最优成绩。

## 三、阶段A：完整raw冠军配方基准

从相同公开初始化重新训练一个学生，**不是恢复旧run，也不是接着旧最佳断点微调**。

| 项目 | 训练前固定设置 |
|---|---|
| 数据 | 官方原始30,344图 / 18,513 Study / 11,055患者，零剔除；原图与CSV只读 |
| 模型与输入 | ConvNeXt V1 Tiny；768全图EXIF+RGB+等比例LANCZOS letterbox |
| 监督 | 逐图十类加权BCE，逆Study视图数权重使Study等权；不改变官方0/1标签 |
| 类别权重 | 按训练Study统计`sqrt(negative/positive)`，不按弱类手工改权重 |
| KD | α=0.2，T=2，两轮渐进；先按教师/学生pos_weight对齐每视图logit，再温度化、sigmoid并平均 |
| 原始缺缓存16图 | 硬BCE系数完整为1，KD为0；保留全部原图，绝不生成假soft label或静默丢图 |
| 优化 | AdamW，backbone 5e-5/head 5e-4，WD.05；8图×累积4=32图，尾窗按实际图数归一 |
| 正则与EMA | dropout.2、drop_path.1、grad clip1；EMA.999且use_warmup/warmup_power.75 |
| 增强 | 与冠军一致：水平翻转、±10%亮度/对比度、±5°旋转；保留全胸，不增加随机裁剪 |
| 日程 | **固定训练9轮，但LR horizon保持25轮**；1轮warmup、cosine、min ratio.05 |
| 检查 | 每完整轮全部图恰好一次、真实optimizer/EMA更新与AMP跳步，完整断点；无逐轮valid |
| 唯一valid | E9实际FP16参数在完整1,422图/859 Study上评估一次，hflip2后Study概率均值 |

历史041的第9轮LR仍约3.814e-5；把horizon改成9会降到2.5e-6，属于不同配方。历史前9轮纯训练约3小时、含验证保存约3小时13分。本轮图片多16张、软件/机器环境与数据读取条件可能变化，速度以首完整轮重新校准。

A只是训练链与配方迁移验收，不是本周主要突破动机。粗否决门槛预先固定为：完整valid复现且Macro AUC≥0.800，训练数据完整、参数有限、每轮真实更新。低于门槛或数值/文件错误即停止流水线，不自动重试、不改门槛追分。这个门槛不是显著性或线上收益证明。

## 四、阶段B：本周主要提分候选

A通过质量否决后，采用上述已冻结配方，从公开初始化分别训练seed44与seed43两个最终学生，各固定9轮、LR horizon25。两者依次运行，**不训练任何教师**。

训练内容为全部官方train加全部official valid：**31,766图 / 19,372 Study / 11,283患者**。原始split和路径保留；用显式授权的混合数据集启用训练增强，重新按全体训练Study计算P2权重与逆视图权重，不把valid路径伪装成train，不因两split独立归一而无意额外加权。

旧OOF覆盖的30,328图继续原α=.2蒸馏；原train中缺缓存16图及valid的1,422图使用系数1的BCE。虽然旧教师也有valid预测，本轮不额外构造新的软目标来源，以降低实现与血缘复杂度。所有真实标签保持原值。

并入valid的动机来自**有标签train/valid的已知差异**：valid的复查病例更多，增加这些可合法使用的真实标签比补16图更有实际意义。它不能保证消除隐藏人群差异，且新增患者只有228，仍可能没有平台收益。

最终候选在并训前冻结：

1. **主候选：seed44最终E9 EMA，单Tiny768+hflip2，Study内全图概率均值。**
2. **备选：seed44与seed43最终E9 EMA全十类等权概率平均**，各自相同TTA/预处理/Study聚合。只减小随机训练方差，不按类拟合、不扫权重、不从并训valid选胜者。

双seed不保证优于单seed；历史单学生已经在线优于某些融合，因此保留单模型作为主候选。训练后只做来源、完整性、确定性和接口复核，不给并训valid的训练内指标冒充泛化分数。也不能把原OOF教师缓存当作新学生内部切分的严格嵌套折外评价。
