# 未清洗重构：独立训练路线复核

2026-11-05，香港时间。本报告审阅活动训练/推理调用链、当前 DINO 全部训练记录、E0/E1/E2 与教师/蒸馏/冲刺结果及有关 Git 历史；未逐行审阅全部归档副本，未运行训练或读取测试图像。用户本轮明确重新授权从官方原始未清洗数据训练。

**结论：当前旧 DINO 权重不能替换提交；现有证据也不足以判定充分训练后的 DINO 必然失败。最有依据的新增实验是原始数据上的独立 DINO 表征与严格折外 CNN 对照，再通过另一患者折确认和全量重训决定最终组合。继续沿小 official valid 手调弱类/同源集成不值得优先投入。**

## 2. 源码没有发现“只取首图”的问题

- `reconstruction/data.py` 按完整 Study 载入所有图片，原始标签在 Study 内必须一致。`study_packs` 仅组织执行，不截断大 Study；每轮核对 Study/image 全覆盖。
- `breakthrough/model.py` 使用 CLS 与非 register 的全部 patch 均值。先按图算 logit，再使用稳定的 `logit(mean(sigmoid(z)))` 得到 Study 输出；训练和开发评估一致。FP16 编码，patch与Study聚合转FP32。
- 尾部梯度累积按实际 Study 数归一；EMA只在有效更新后推进，并有早期暖启动；学习率按累计更新恢复，不在断点处重启。正类权重仅来自训练 Study。
- DINO的底层峰值学习率约6.87e−7、顶层1e−5、分类头2e−4，属于保守适配。没有足够实验证据证明立即大幅加大学习率一定更好。
- 旧配置强制至少8轮；新实验可改为最多18轮、至少4轮、patience4，但不得将首轮落后误称充分训练失败。数值异常、覆盖或标签错误应立即停止。
- 旧正式运行峰值约3.28GB。pack16/chunk8冒烟并未证明比pack4/chunk2更快，不能由显存空闲推导扩大微批一定提速。最高视图数完整 Study 的真实前后向验证更有价值。
- 单DINO 86,600,458参数，FP16纯参数约173.2MB，具备500MB内与CNN组合的空间；实际打包体积与赛事计时仍须实测。

## 3. 历史结果限制了哪些方向

E1注意力比E0提高0.001399，但患者配对区间跨零；E2全局3轮、局部2轮的最佳都停在epoch0，五区域约五倍计算。因此“加局部/注意力就突破”没有依据。无条件同患者均值曾从0.807556降到0.777570，且患者配对区间完全为负，不能把测试患者多Study结构直接当作平均平滑授权收益。

Tiny512纯BCE后期训练loss和AP继续改善而AUC下降，KD也有同类现象；已经证明只看loss下降或延长训练不足以保证排名变好。Robust三成员仍属同源ConvNeXt，增加模型数没有增加已证实的平台收益。

旧clean仅排除16/30,344图，18513 Study全部保留。恢复原图是用户明确要求，必须执行；但仅恢复0.0527%图片没有证据能单独解释或逆转平台退分。

## 4. 选择和晋级应分开

保留竞赛定义的十类Study Macro-AUC选择checkpoint。**不推荐 `(整体+AP-only+单图+5次检查患者)/4`：AP-only与单图高度重叠，简单均分会重复加权同一群体；子集AUC也遗漏跨组正负排序对。** 新组合分数是新的人工目标，不能默认更贴近隐藏测试。

困难切片用于固定晋级门槛：相同患者折的整体、AP-only、单图、至少5次检查患者，以及患者簇不确定性。仅比较单候选和预先固定的全类50:50 CNN/DINO概率均值，不搜索逐类权重。候选自身略弱但固定融合有益，仍可能有互补价值。

完成本阶段后，只有单体或固定融合的整体增量配对区间下界大于0、关键切片全部十类可评估且没有明确退化，才具备进入第二折的依据；不是自动部署资格。未完成训练、缺区间或支持不足均需要复审。跨折确认之后固定配方和训练轮数，再用全部原始train重训。保留平台最佳041，不因开发点分微升自动改写submission。

恢复16图后，应按唯一Study key重排参照，患者和十类标签严格一致；视图列表改变则记录原始差异。此时只能称相同Study比较，不能称相同图像消融。旧CNN训练患者必须再次与新dev患者检查隔离；若分折移动患者，旧参考可能不再合法。需要更严格同输入比较时，以冻结CNN权重在原始dev全部图像上重推理，不更改其参数。

新 `raw_rebuild/comparison.py` 已实现这一CPU诊断与保守阶段门槛，输入只限调用方已冻结的训练内开发预测，不读取图片、模型或test，不改变checkpoint选择，也不生成CSV。7项CPU检查通过，覆盖身份/标签、重排、恢复视图、缺失/不足CI、切片退化、未完成禁止晋级和融合独立资格。阶段CI要求至少100个有效患者重采样且有效率至少90%，缺失支持不会自动通过。

以旧第1轮缓存进行300次患者重采样的真实机械复核也通过：固定50:50融合Macro为0.793661，相对CNN为−0.002135，95%区间[−0.005711,+0.000901]；AP-only、单图、至少5次检查患者差值区间分别为[−0.011407,−0.003878]、[−0.011610,−0.003876]、[−0.017056,−0.001233]。因此旧第1轮固定融合也不符合晋级条件。它不是充分训练后的结论，也不是用旧清洗结果替代新原始数据实验。

以上方案能给出明确执行优先级与拒绝条件；隐藏测试没有标签，不能从现有事实推导“这次训练必定超过76.92”。
