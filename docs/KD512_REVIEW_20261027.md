## 后续成绩为什么下降

| 指标 | E7 | E12 | 观察 |
| --- | ---: | ---: | --- |
| 训练混合loss | 0.670715 | 0.501150 | 下降 |
| 训练硬BCE | 0.790836 | 0.572065 | 下降 |
| 训练KL×T² | 0.190227 | 0.217493 | 后期回升 |
| valid非加权BCE | 0.470924 | 0.424502 | 下降 |
| valid Macro-AP | 0.431146 | 0.436121 | 上升 |
| valid Macro-AUC | 0.805594 | 0.800910 | 下降 |

1. **逐类排名退化是确定观察，过拟合是合理解释而非单一已证实病因。** 类别1、4、8后期下降明显，其他类别仍有改善；类别1对Macro-AUC的负贡献约0.004032，类别4约0.002117，超过净下降0.004684是因为其它类别抵消了一部分。BCE下降不能替代AUC，且没有train AUC、逐例/分层预测，不能证明具体记忆机制或错标原因。
2. **训练目标与排名指标不同。** 当前优化加权BCE+KL，验证loss是Study非加权BCE，不能直接比较它们绝对大小；验证BCE/AP改善也不保证每类正负排序改善。有限样本、类别权重和共享特征可使类别间表现分化。AUC导向优化是单独研究路线，不能因论文结果直接把新loss加入本工程。[Deep AUC研究](https://arxiv.org/abs/2012.03173)
3. **教师与硬标签的目标可能存在拉扯。** KL在E8最低0.186855，E12升至0.217493（+16.4%），硬BCE却持续下降，说明在线学生逐渐偏离固定教师目标。训练KL来自在线学生，验证来自EMA；这不是直接证明应增大alpha或更换教师的证据。教师OOF在1/4较弱，且与official valid不是同一集合；避免过度归因。
4. **有效阳性样本少，排名容易波动。** 类别1 valid仅24阳性Study/16患者，类别2为37/13。连续后期退化值得研究，但不能把选出的最佳epoch视作无偏泛化分数。
5. **当前余弦降速偏慢是值得检验的日程假设。** E7学习率4.30455e-5仍为峰值86.1%，E12仍为58.7%，尚未进入原25轮日程的低学习率末段。项目使用自定义按优化器更新的warmup+cosine；官方余弦文档解释周期长度如何影响降速。[PyTorch文档](https://docs.pytorch.org/docs/2.10/generated/torch.optim.lr_scheduler.CosineAnnealingLR.html)

同为E11时，KD AUC .801980、BCE .793379，KD仍高.008601；不能把后期下降简单归咎于蒸馏。原25轮若继续到低学习率区是否会回升，当前早停记录不能证明；保留事先登记的停止结果，不为追分篡改或恢复原run换配置。

## 值得做的改进，按成本与证据排序

1. **先固定现有成绩，再复用已有模型。** 导出E7为FP16并保存valid概率，独立复算十类和患者配对区间。随后只做一个预定BCE+KD等权概率融合的CPU诊断；若有收益，再以实际导出的双Tiny固定TTA组合核验T4预算。它不需要新训练，但会增加推理次数，不能凭体积足够就宣称≤100ms。
2. **下一项训练优先一个短余弦日程对照。** 候选新run为`028_tiny512_kd_short12_seed43`，仅把`epochs`从25改12，其余峰值LR、alpha/T、seed、增强、EMA、数据、patience等不变。注意现代码里epochs同时控制最大训练预算和衰减周期，不能声称只改了一个独立于预算的调度参数。纯CPU预览与027逐项比较，仅epochs/output不同；同一优化器步位置，E7的LR会更低。这是降低后期大步更新的假设，改善不保证。
3. **再决定768或额外seed。** 768应与相同目标/日程的512作对照，才知道分辨率收益；当前类别1/4下降没有证明是分辨率不足。已有两个学生可以先研究互补，不必立即训练很多成员。
4. **损失/教师和权重平均后置。** 降峰值LR可以替代短日程作为另一项单因素试验，不同时改；ASL、十类独立alpha、更强增强或重训教师都缺少目前必须投入的证据。相同架构/初始化模型的权重平均可作为将来节省推理成本的候选，但不保证等价概率集成，且需完整父模型来源与实际验证，不把当前EMA误当成跨模型平均。[Model soups](https://proceedings.mlr.press/v162/wortsman22a.html)

短12轮实验预计约1–1.5小时，不增加单模型参数量/前向次数；当前只是参数预览，未创建028或训练。是否执行，在本次E7部署验收后再定。不同教师/学生容量与更早教师检查点可能影响KD，相关文献支持做对照，不保证本任务E13能提高学生；仍保留原A和E13而不立即改来源。[KD研究](https://arxiv.org/abs/1910.01348)
