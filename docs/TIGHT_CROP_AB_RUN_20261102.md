# Tight Crop 配对实验与自动运行

本轮已获用户授权：先验证 AP 泛化方向，裁剪耗时约 26.7ms 不再作为实验启动门槛。
这不改变正式提交的时延要求，也不代表候选可以部署。

## 固定实验

机器配置以 [预注册 JSON](TIGHT_CROP_AB_PLAN_20261102.json) 为准。A 与 B 均包含
ConvNeXt V1 Tiny、Base 两个成员，对应成员从相同的历史 FP32 EMA 初始化，seed=48、
固定 2 轮。使用完整 Study 的全部视图训练，固定 OOF 蒸馏与原有损失；只评估 E2
`last.pt` 的最终 EMA，不以 `best.pt` 或逐轮 valid 指标挑选结果。

A 为完整原图解码加等比 letterbox；B 为同样完整解码、已审阅的主体 Tight Crop、
等比 letterbox 和训练期随机擦除。全部输入 768，均使用一个缩放比例后居中补黑。
不采用 EXACT-BLACK、旧 safe-crop 或尚未验证等值的 draft 加速版。

B 的擦除概率固定 50%，每次仅一个面积为内容框 0.5%–2% 的黑块，归一化前执行。
触发后位置一半均匀采样、一半偏向内容框外侧 20% 区域；不根据亮度抹除组织。
擦除使用独立 RNG，A/B 的共同几何增强随机流保持一致；valid 与推理完全关闭擦除。
这评价的是“裁剪＋擦除”组合，不能单独归因裁剪；随机遮挡也不保证消除文字捷径。

历史最优 0.8176 来源于不同冻结策略/训练配置，不是本轮配对 A。历史 044 的
84.82ms 与 AUC 单独复算为参考；本轮共同使用完整解码，不能沿用它的 draft 时延。
历史 checkpoint 已受本地 valid 选择影响，本轮固定设计不能消除既有选择偏差。

## AP 是主要判据

AP-only 是 Study 所有图像均为 AP；当前 valid 有 442 个这样的 Study。报告其总体
及十类 AUC、每类阳性/阴性数、单图/多图 Study 描述性切片，和以患者为单位的
1000 次配对 Bootstrap 95% 区间。重采样保留患者全部 Study，但概率聚合只在
`Subject_id + Study_id` 内用 FP64 等权均值，绝不跨 Study 平滑。

主要对照为 AP-only 的 B−A。总体 AUC 不涨不自动否决 B；AP 增益区间跨零时报告
不确定，不把点估计称为已证明提升。总体、非 AP、单图/多图结果仍完整公开。
只有一个固定种子，Bootstrap 反映患者抽样不确定性，不覆盖训练随机性或线上域差异。
不按本轮结果自动调超参、重选 checkpoint、重训、提交或读取 test。

## 自动化与留存

顺序运行 A_tiny、B_tiny、A_base、B_base，随后自动做固定 FP16+hflip2 融合评估及
历史 044 参考评估。控制器单实例锁防止重复启动；源文件及计划哈希冻结，异常写入
状态文件，完整断点最多自动恢复一次，不能无限重训。每阶段保存日志及完整证据。
