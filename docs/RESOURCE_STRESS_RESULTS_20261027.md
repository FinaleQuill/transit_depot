# 4090端到端计时、资源限制与等值预处理加速

2026-10-27（香港）。实际设备只有RTX4090，未进行真实T4测试。以下全部使用固定valid图片，FP16、batch1串行、5图预热、三轮100图，计入读图至CSV实际写出；按每图三轮均值再100图平均，模型初始化不计时。候选均固定hflip2，不使用CLAHE或DALI，没有跨图预取或预计算预测缓存。

输入100图覆盖53个完整Study、40患者，预热5图覆盖4Study/4患者，患者不重叠。seed20261027仅按身份/Study图数选择，不使用标签、质量或模型输出。原图为L模式JPEG、约3.15–7.77百万像素；图片与原valid清单SHA核验通过。

## 瓶颈与变更验证

旧流水线的原生4090均值为119.014/136.160/207.629ms（512/768/混合）；分段诊断一轮中，CPU读图/EXIF/转换/缩放/归一化约107.821/116.916/181.862ms，模型前向CUDA事件区间约6.692/6.790/12.892ms，结果汇总与CSV约.20ms。CUDA事件区间包含主机提交间隙，不能当作孤立kernel算时；诊断轮与正式三轮不是同一次测量，不能逐项拼成正式总数。

等值修改是：L灰度先LANCZOS缩放，再在RGB画布展开；EXIF在图像内存中处理以避免无变化复制；同一predict_image调用内共享尺寸/视图张量。其它模式、16位拒绝、几何取整、float32归一化、FP16前向、sigmoid/TTA和CPU概率融合算术保持原协议；不改训练、教师或数据，不跨图缓存。

验证包括269项CPU测试/365子测试，208组模式/EXIF/形状用例、105张真实valid图×两尺寸210次归一化数组逐字节一致。真实CPU预处理配对均值512从105.580→55.418ms，768从117.673→68.629ms；三个原有候选的新版100图输出概率与旧原生结果最大差值为0。CPU时间并非端到端时间，表格中的新版结果是另外实际重测所得。

旧deploy源码SHA `fd70c10e83a7fc0daa01782d62d0c941f0b2f06b87e59c0b2af89d9a22395849`独立封存，新版为`7cfc9a8df406cf81bb019081464513e895b03ac3284bb88a7d49b588f1fc2ece`；原始时序、权重和归档都保留，不把旧测量追认成新版。

## CLAHE、DALI与真正的下一步

用户所述队友方案是CLAHE对比度增强，并非预测缓存。当前训练/上述测试都未加入CLAHE。DALI官方确有支持CPU/GPU的fn.clahe，环境当前未安装；GPU支持不证明本项目batch1端到端会更快，也不证明AUC提高。若采用，要固定参数/操作顺序、验证CPU/GPU实现一致性和依赖复现，计入单图全部成本，不跨测量图片预取隐藏工作。[DALI官方CLAHE](https://docs.nvidia.com/deeplearning/dali/user-guide/docs/operations/nvidia.dali.fn.clahe.html)

当前优先训练效果复盘：先完成029完整valid实际FP16及一次固定512+768概率诊断，再决定下一训练。主候选仍为027；新增训练默认备选Tiny512 seed44，不因双768本机速度看起来可行就直接启动多个768学生。
