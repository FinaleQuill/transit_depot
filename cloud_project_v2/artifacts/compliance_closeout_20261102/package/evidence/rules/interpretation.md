# 规则来源与包结构解释

本目录中的 `official_rules.pdf` 与 `official_supplement.pdf` 是正式来源原件；同名 `.txt` 保留完整提取文本并包含 `===== PDF PAGE n =====` 页标。正式规则和正式补充优先于页面、FAQ、群消息或口头答疑。

## `pretrain_model/` 的性质

正式规则附录 A 第 5 页的目录树写作“提交示例”，因此该树中的 `pretrain_model/` 是示例目录，不能单独推导出必须将所有原始预训练二进制放入材料包。正式必须项是第 1 条模型来源、公开链接、完整许可证、上游训练数据说明和 SHA-256，以及第 10 条的可复现材料。补充说明第三节（五）明确：不参与最终推理的教师权重文件不必放入包，但教师哈希和许可证仍须申报。最终实际加载的推理权重和必要配置须按第 8 条计入并提供清单。

因此本包应携带可打开的来源/许可/哈希/血缘证据；是否携带原始大权重二进制不能用“示例目录”冒充强制条款，也不能漏报教师哈希。

## 计时口径冲突边界

正式规则第 7 条及正式补充第九节写“单张图片”平均耗时。曾转发的群公告若使用 Study 级口径，必须作为待官方书面澄清的外部通知处理；本材料不把它改写成正式规则原文。
