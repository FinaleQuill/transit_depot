# 推理与后处理声明

## 固定推理

每张图独立进行固定前向；模型以 `eval()` 模式运行，参数、Dropout 和后处理参数冻结，随机种子为 43。TTA 仅为预先固定的 horizontal flip 两视图平均（hflip2）；不存在随机裁剪、随机擦除或其他随机推理算子。LayerNorm 使用模型中冻结的学习到的仿射参数，按该层定义对当前输入计算确定性归一化；本模型没有可更新的测试集 BN 统计量。

## 聚合

单图概率先保留十类完整向量；同一 `Subject_id + Study_id` 的多图概率做固定 FP64 算术均值后输出。该聚合不拟合权重、不使用标签、不使用测试集统计量，也不跨 Study 混合患者的不同检查。当前包没有患者级跨 Study 聚合；若未来采用患者级聚合，必须在申报中明确其为不拟合任何参数的确定性聚合。

## 禁止事项声明

推理阶段没有梯度更新、测试时训练、跨样本自适应、测试集统计量拟合、阈值拟合、NMS 参数调整或概率校准。`predict.py` 和 `cost.py` 通过同一 `submission_runtime.load_submission_predictor` 加载逻辑和相同的固定推理入口；一致性核验状态以 `cost_consistency_report.md` 为准。
