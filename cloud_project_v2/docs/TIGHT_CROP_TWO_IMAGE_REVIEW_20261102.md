## 实现

[tight_crop.py](../tight_crop.py) 不使用边缘扫描寻找黑带，流程为：

1. 完整灰度解码，在最长边 512 的等比分析帧上执行 OpenCV 正确 Otsu，提取亮组织种子；
   小核开运算、闭运算与中心大连通域减少细碎结构影响。
2. Otsu 亮区不能代表暗肺野，因此另建较低亮度支持掩膜，其阈值为
   `clip(floor(0.12 * Otsu), 2, 12)`；闭运算及外轮廓填充后选取与种子重叠的主体。
   其他较大支持分量也受到保护，避免直接忽略侧边组织。
3. 对支持区取凸包和包围框，每边按该框宽/高外扩 **5%**，至少 32 个原图像素。
   5%-10% 是接口允许范围，本轮固定用 5%，没有为了消字改用负 margin。
4. 按实际分析宽高分别映回原图，左/上向外 floor、右/下向外 ceil，限制在原图内。
   保留区太小、种子未包含或裁外还有较大组织支持区时精确回退完整原图。
   已废弃旧单边 8% 黑带上限，否则 AP_04 的大片空白无法处理。
5. 裁后只使用一个缩放因子 `768 / max(crop_width, crop_height)`，短边居中纯黑填充；
   不拉伸成方图，不随机中心裁剪。

这些固定参数只是两图演示配方，不是由完整 train 校准过的通用参数。掩膜是亮度支持
包络，不是肺分割；闭运算可能把导线连入身体，低阈值也可能遗漏很暗的外围组织。
5% margin 和种子保留检查不能证明解剖完整。此原型尚未满足部署或训练准入条件。

## Random Erasing

独立函数 `random_erasing_u8` 已实现：仅训练模式，以 `p=0.5` 触发一个随机小矩形，
面积约占图像内容区的 0.5%-2%，在归一化之前填原始像素 0，验证/推理模式完全不擦。
显式 worker RNG 控制可重放性；正式训练数据管线尚未接入，原有增强也未叠加修改。

没有按高亮/高对比度定向擦除，因为病灶、胸壁和医疗器械都可能满足这一条件。
均匀位置擦除只能作为减轻局部依赖的待验证正则化，不能保证模型转向肺实质，也不是
设备去除器。“模型主要在认字/看导线”目前是合理待检验假设，不能由两张图片确认。

[AP_05 擦除演示](../artifacts/tight_crop_two_image_20261102/train_005642/training_erasing_comparison.png)：
固定 seed=2，本次实际触发，面积占内容区 0.9336%；AP_04 的 seed=0 本次未触发。
这两个展示种子只用于说明触发/不触发，不代表总体概率实测。主对比图和 768 结果没有擦除。
