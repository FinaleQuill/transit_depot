# 局部看片：弱监督与 100ms 约束下的预研

日期：2026-11-02（香港）。性质：设计评估，未新增训练、模型前向、图像扫描或测试集读取。
当前 A/B 和已排队的自动复盘保持原协议。本文件不改变其源码、参数、早停或评估选择。

可行性结论：保留这条研究方向，优先考虑**共享一次骨干前向的全局分支加局部注意力**。
不推荐把固定中心裁剪、四块拼图或额外多个 768 前向直接接入生产。
两阶段定位再放大不是原理上不可行，但在当前耗时证据下只能列为后备研究，不能承诺 T4 合格。

## 1. 局部关注与局部放大解决的是不同问题

| 目标 | 可能的机制 | 无法由此保证的事 |
| --- | --- | --- |
| 减少背景对分类结果的影响 | 在既有特征图上学习按类别的空间权重 | 不保证权重不会关注文字、电极和导管 |
| 保留微小病灶的原始细节 | 从原图取正确 ROI，再放大到网络输入 | 需要可靠定位；不能切掉其他类别的证据 |
| 抵抗设备与文字相关性 | 训练增强、跨患者验证、错误与注意区域复核 | 黑块擦除不能证明模型已消除捷径 |

注意力只重加权已经计算的特征，不能恢复原图缩到 768 时丢失的像素。
Tight Crop 的最大约 1.216 倍线性放大来自有偏的 96 张审阅样本，不能当作全量放大率或精度结论。
当前 B 同时改变裁剪和随机擦除，最终即使 AP 上升，也只能归因于这个组合。

“一个病只需要看一块”只能作为部分局灶性表现的假设。胸片还包含整体形态、双侧比较及边缘征象；
例如心影比例、肺尖及肋膈角相关信息可能无法由一个中心热点替代。
这里是医学影像任务的一般说明，项目尚无已核实的十类数字 ID 与病名映射，不能据此给某类指定裁剪范围。
侧位片也不能直接套用正位片的左右肺野假设。

## 2. 当前模型和计时事实

- `model_overnight.py` 使用 ConvNeXt V1 Tiny/Base，当前为全局平均池化、归一化、分类头，没有 ROI 分支。
  池化后特征维度分别为 768/1024。768 输入的末级特征通常约 24×24、步长 32，
  这是架构预期，未为本预研启动模型验证尺寸；未来实现必须检查实际张量。
- 当前 `tight_crop_ab_evaluate.py` 的 hflip2 每个模型执行两次前向；Tiny+Base 共四次。
  “增加局部头”和“增加完整模型前向”必须分别计价。
- 分类头在全局池化后还有归一化，直接将 FC 权重乘空间特征并不是当前完整分类器的严格 CAM 分解。
  Grad-CAM 通常还需反向传播，不是零成本定位器；新空间分类头需要训练，不能作为加载旧权重后的无损开关。

| 既有测量 | 数值 | 适用边界 |
| --- | ---: | --- |
| 044：Tiny+Base，draft768，hflip2，端到端 | 84.820ms | 2080Ti，100 图、5 预热、3 轮；非当前完整解码 B |
| 043：单 Base768，端到端 | 74.550ms | 2080Ti 历史另一配置，不能据两者差值推算新模块成本 |
| 完整灰度解码 | 32.410ms | 16 张固定、有偏 train 样本的 CPU 预检 |
| 已解码原图上的冻结 Tight Crop 检测 | 26.832ms | 同一小样本；含大图缩至 512 的成本 |
| 完整解码加冻结检测 | 59.241ms | 同一小样本实测，尚不含完整模型与输出 |

最后一行在该样本上的 100ms 算术余量仅为 40.759ms，但不能外推为正式候选预算。
84.820ms 也不能直接加上 26.832ms 得到 B 的时延：解码、复用及配置不同。
证据见 [CPU 预检与优化备选](TIGHT_CROP_LATENCY_OPTIONS_20261102.md)、
`artifacts/tight_crop_ab_20261102/latency_preflight/` 和

## 3. 各路线的取舍

| 路线 | 是否真正增加局部输入细节 | 主要成本和风险 | 本轮判断 |
| --- | --- | --- | --- |
| 固定中心 ROI 替代全图 | 可能 | 肺尖、外周及底部证据缺失；AP 定位变化大 | 不作默认生产方案 |
| 2×2 局部拼接为 768 | 不保证 | 每格约 384；原图分成四块再等分拼回基本不增加采样密度，另有接缝与位置破坏 | 不优先 |
| K 个 ROI 各做 768 前向 | 是，取决于 ROI | 约 K 次骨干成本，还可能叠加翻转；弱标签不保证热点正确 | 当前不优先 |
| 小定位器 + 一个 768 主模型 | 是 | 串行定位、坐标传递、取框及第二阶段；错定位不可逆 | 后备，须整体计时 |
| 一个骨干 + 全局/局部双头 | 否；重新利用已有特征 | 小头开销、需要训练、仍可能关注设备 | 首选研究假设 |
| 仅训练时使用局部教师，部署单学生 | 教师可；学生受自身输入限制 | 离线算力与 OOF 成本，不能蒸馏回已丢失像素 | 后续备选 |

拼图只在先去掉无关内容、将有限像素重新分配给正确区域时可能有价值；它不会凭空增加像素预算。
多裁剪也不应把同一张图的各块当成拥有独立 Study 阳性标签的训练样本。

## 4. 首选候选：保留全局路径的空间 MIL

未来如获准实现，先只改分类头，复用 Tiny 骨干同一张特征图 `F[C,H,W]`：

```text
同一张图、同一次骨干前向 -> F
    全局路径：保留既有 GAP/归一化/分类头 -> g[10]
    局部路径：轻量 1×1 投影 -> 分类别分数 s[10,H,W] 和注意力 a[10,H,W]
              a 在空间维 softmax；l[c] = sum_u a[c,u] * s[c,u]
    图像输出：sigmoid(g[c] + lambda[c] * l[c])
Study 输出：该 Study 全部图像概率的固定 FP64 算术均值
```

`lambda` 为训练参数，初值可设为 0，先保持全局输出；局部分支逐步学习，不用 valid 搜索十组融合权重。
这个初始化及约束仍是候选设计，具体训练协议需预先固定。局部头不改变提交的同 Study 等权均值。
这里的“实例”是空间特征位置，其感受野可能很大，并非已经定位好的独立病灶块。

若末级实际为 Tiny 的 768×24×24，一路十类 1×1 投影约 442 万 MAC，
分数和注意力两路约 885 万 MAC；相对于再次运行完整骨干，计算规模小得多。
这只是算术量估算，归一化、内存读写与 kernel 启动仍需测量，不能写成“已增加不足 1ms”。
先用末级特征；使用较高分辨率的中间层再投影属于第二个候选，不同时引入多尺度、多块和新损失。

训练必须保持弱标签语义：对 Study 聚合后的十类概率计算既有监督损失，不能强制阳性 Study 的
每张图、每个块都为阳性。先用温和的软池化，不采用容易被一个文字或电极激活的硬最大池化。
现有 OOF KD 若继续使用，保持完全相同的教师、缓存、温度和权重作为控制变量；
局部视野/遮挡与完整图教师目标不一致的问题另做分析，不能通过临时增大 KD 权重掩盖。

保留全局分支只能降低遗漏信息的风险，不能保证模型真的使用全局信息，也不能保证注意力具备医学解释。
后续应在固定 train 样本检查翻转/缩放对应关系、文字设备关注情况、外围组织覆盖及错例。
没有病灶框时，不能报告定位 IoU 或宣称“已找到肺部病灶”；图好看也不是泛化证据。

## 5. 两阶段法何时才值得做

只有在单骨干方案遇到明确的细节瓶颈，并且可重复地定位到相关区域时才升级。
建议的候选是一次低分辨率全图定位、至多一个 ROI 从原始解码图取出再做 768 分类，
全图分支提供上下文；ROI 始终等比缩放和补黑边。低置信度回退及阈值预先固定，
不得根据测试集分布、累计统计或测试标签调整。

完整串行时间必须包含：

```text
T = 文件读取与一次共享解码
  + 定位输入缩放与定位器前向
  + 坐标传递、原图取框与 ROI letterbox
  + 主分类器前向（含实际启用的 TTA）
  + 固定融合、Study 汇总与结果写出
```

不要先 draft 解码定位再为 ROI 重新完整解码而漏计第二次解码。
更合理的资源分配是考虑用“低分辨率全图 + 高分辨率 ROI”**替换**现有 hflip2 的预算，
而不是叠加第三、第四路；取消翻转有精度代价，必须作为完整新候选评估。
也可用离线教师生成训练用定位监督，但 CAM 仍可能定位 PORTABLE/导线，不能把它当真实框。
如新增用于蒸馏的训练软标签，继续严格患者 OOF；不引入来源/许可不合规的医学分割权重。

CPU/GPU 异步、多进程 loader 可以加速训练吞吐，不能靠并发隐藏正式 batch1 串行端到端成本。
真实 T4 才能证明不超过 100ms，2080Ti、MAC 数或历史别的配置只能提供筛选证据。

## 6. 等本轮 A/B 完成后如何决策

1. 先读最终 AP-only、AP 单图/多图、逐类、患者配对区间和实际时延；单看总体 AUC 不足以否定
   AP 改善，但 AP 的很小点差、区间跨 0 也不能称为已拯救泛化。B_tiny 最佳 AP 的中途差值约
   +0.000421，仅是 native 训练验证的中途数值，不是最终 FP16 结论。
2. 若 B 的 AP 收益足够一致而时延不合格，优先压缩已证明有用的流程；无需立即引入第二个网络。
   若 B 无收益，也不能推导所有局部方法无效，只能否定当前裁剪加擦除组合在该验证协议中的收益。
3. 若继续局部注意力研究，第一组对照只改变局部头，其余预处理、擦除、初始化来源、KD、
   seed 和早停协议相同。训练内部患者隔离实验先作选择，既有 official valid 再做冻结候选的
   探索性比较；它已多次参与选择，不能当作未触碰的新独立评估集。
   **当前全 train 微调过的学生不能当作无泄漏的 train 内 CV 初始化**：它已见过该内部验证折。
   真正的 CV 需使用没见过该折的初始化/折内模型，或从合规 ImageNet 权重起训，并单列计算成本。
   折内 KD 的教师和软标签血缘也必须排除该验证折；现有缓存逐样本 OOF 并不自动保证新外层 CV
   隔离，因为给其他训练样本产软标签的教师可能已经见过这个外层验证折。
4. 当前 valid 已被多次选择且本轮 AP 参与早停，患者 bootstrap 是所选模型的条件不确定性，
   不能消除反复选模偏差。未来不靠反复浏览同一 442 个 AP-only Study 调局部头。
5. 新 head 需要版本化架构配置、严格 checkpoint 加载、训练/推理共同实现和输出一致性核验；
   不能静默修改 `model_overnight.py` 后继续加载原结构权重。实际部署资产仍须 ≤500MB。
