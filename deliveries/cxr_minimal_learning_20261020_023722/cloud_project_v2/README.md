# CXR 768 主线学习包（精简版）

这份包只保留当前 **768 原图 + 正样本加权纯 BCE + 患者隔离五折** 主线。先打开 [LEARNING_GUIDE.md](LEARNING_GUIDE.md)，它按文件和函数讲执行顺序，不再展开长篇网络理论。

## 文件清单

| 文件 | 一句话用途 |
| --- | --- |
| `cv_splits.py` | 决定哪些患者/Study属于哪一折，并读出该折的图片记录。 |
| `dataset.py` | 只放主线需要的清单解析、目录定位、等比例缩放补边小工具。 |
| `dataset_overnight.py` | 把记录变成768张量、组成微批，并按Study汇总概率。 |
| `model_overnight.py` | 创建ConvNeXt V2-Base，输入图片、输出十个logit。 |
| `train_overnight.py` | 完整训练一折，包含加权BCE、累积、EMA、验证、早停、保存和恢复。 |
| `run_all_folds.py` | 按每折一个epoch轮转，调度五折并保留恢复/OOM逻辑。 |
| `inference_overnight.py` | 后处理主线：对最佳EMA权重做TTA/五折概率平均并输出结果。 |
| `metrics_overnight.py` | 放集成实际复用的指标检查、逐类阈值搜索和指标计算。 |
| `runtime_compat.py` | 为代码导入准备必要的跨平台兼容处理。 |
| `run_overnight.sh` | 将默认参数交给五折调度器。 |
| `requirements.txt` | 第三方库依赖，PyTorch/timm等通过这些依赖提供。 |

九个Python文件保留中文注释。训练、验证和断点恢复所需函数没有因为教程只重点讲两三个函数而被删掉。

## 精简了什么

不包含任何Tiny/Highres旧模型或旧训练入口；不包含旧推理分流大文件、旧版文档、测试集合或显存探针。也不含 `data/`、`runs/`、图片、CSV数据、`.pt`权重、缓存、日志和虚拟环境。

为保证必要代码不少、历史大文件不混进来，学习副本做了两处依赖整理：

1. `dataset.py`只保留当前主线真正引用的公共常量、错误类和函数，移除没有调用的通用Dataset/增强/混合实现。
2. 原来散落在旧训练文件里的指标函数，完整抽到`metrics_overnight.py`；五折调度器直接调用`inference_overnight.py`。源码指纹清单同步为本包九个模块，预处理只保留768。

`pos_weight`是BCE内部的正标签权重，Study视图权重是另一层样本权重；当前主线没有附加Rank/Focal损失。

## 与当前训练的关系

这是独立学习副本：原项目只读，本次没有操作tmux、训练进程或GPU，没有导入/运行项目、测试或训练入口。代码与正在运行实验的路径/源码指纹不同，用于阅读整条主线，不用于接管当前训练目录。实际执行仍需另行准备清单、五折计划、原图、提交模板与权重资源。

默认微批2、累积16、有效32张图、workers8。默认值可以被命令行/环境变量覆盖；本包不把默认值当成实时进程实参。

`PACKAGE_MANIFEST.json`记录源代码哈希、函数保留和依赖检查。检查全部是标准库静态解析，没有运行训练。
