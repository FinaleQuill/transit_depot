## 模型拆解：把已学过的 ANN，变成会处理图片的 CNN

### 先把 ANN 的知识保留下来

你熟悉的全连接层可以写成 `h = 激活函数(Wx+b)`。CNN 仍然由可学习权重、加法、非线性函数组成，仍然用损失函数和反向传播更新参数。新的地方在于：怎样组织图片里的数，以及哪些输入之间应该共享权重。

一张 RGB 图片不是一长串彼此无关的数，而是 `3×高×宽` 的网格。相邻像素之间往往有结构关系。若把 `3×768×768` 展平成向量，再直接接一个有 512 个神经元的全连接层，仅这一层就需要约 9.06 亿个连接权重，而且左上角和右下角的相似纹理会分别拥有两套参数。

卷积给网络加了两个结构约束：

- **先看局部**：一个卷积核每次只读一个小窗口，对窗口里的数乘权相加，生成一个输出。窗口滑过图片，就生成一张新的网格，叫作特征图。
- **共享同一套权重**：同一个卷积核在所有位置使用同一套参数。某种局部模式即使出现在不同位置，也能使用同一套检测规则。这减少参数，并让模型更适合利用图像的空间结构。

卷积核不是人工写死的“边缘检测器”。训练会学习它的权重。把浅层看作较简单的纹理、深层看作组合模式，是帮助理解的直觉；不能据此断言某个通道只代表某一种疾病或某一个器官。

**CNN 是 ANN 的一种结构，不是另一套学习原理。** 学会卷积如何连接输入后，前向传播、梯度、优化器等知识都可以继续使用。

### 本项目到底创建了哪个模型

`model_overnight.py` 很短，是因为它调用了第三方库 `timm`：

```python
timm.create_model(
    "convnextv2_base.fcmae_ft_in1k",
    pretrained=pretrained,
    num_classes=10,
    global_pool="avg",
    drop_rate=0.2,
    drop_path_rate=0.15,
)
```

这里的 `Base` 是模型规格；`fcmae_ft_in1k` 标识这套预训练权重来自 FCMAE 预训练及 ImageNet-1k 微调配方。使用预训练，意味着从已有视觉参数开始学习本项目的任务，而不是每个参数都从随机数开始。本项目没有在胸片上重新执行 FCMAE 预训练。`num_classes=10` 指定本任务的输出数；它改变分类头，使输出和十类标签对应。

真正的 stem、卷积块和分类头在 `timm/models/convnext.py` 及 `timm/layers/` 下。本项目并没有在 `model_overnight.py` 中重新实现整个骨干网络。模型构建函数没有写 `sigmoid`，所以输出是原始分数 logits。

### 跟着形状走，一次看懂整体结构

PyTorch 的常见逻辑形状是 `N×C×H×W`：`N` 是这一微批的图片数，`C` 是通道数，`H/W` 是高宽。起初的 3 个通道表示 RGB；深层的 128、256 等通道表示网络学出的不同特征，不再是颜色。

以下尺寸来自项目配置和本机 `timm==1.0.30` 的源代码静态核验，没有启动模型计算：

| 位置 | 形状 | 做了什么 |
|---|---|---|
| 输入 | `N×3×768×768` | 每张图片已经完成 Pad、增强与归一化 |
| stem | `N×128×192×192` | `4×4` 卷积、步长 4，把空间边长缩到四分之一，同时产生 128 个特征通道，再做 LayerNorm |
| 第 1 阶段 | `N×128×192×192` | 连续 3 个 ConvNeXt V2 残差块，保持本阶段尺寸 |
| 第 2 阶段 | `N×256×96×96` | 先 LayerNorm 和 `2×2`、步长 2 的卷积，再接 3 个残差块 |
| 第 3 阶段 | `N×512×48×48` | 同样下采样，再接 27 个残差块 |
| 第 4 阶段 | `N×1024×24×24` | 同样下采样，再接 3 个残差块 |
| 全局平均池化与分类头 | `N×10` | 空间平均 → LayerNorm → 展平 → Dropout → Linear |

可以把空间网格理解为“记录哪些位置有什么特征的地图”。越往后，地图越小，但每个位置拥有更多通道，可以保存更丰富的组合信息。四阶段深度是 `[3,3,27,3]`，通道是 `[128,256,512,1024]`；这不是 Tiny 版本的配置。这里的 36 个是**残差块**，不是全部网络层的数量，因为每个块内部还有多项运算。

网络接收的逻辑形状一直可以写成 `NCHW`。代码另有 `channels_last` 内存格式优化时，它不表示你应把数据标签或外部张量形状改成 `NHWC`；逻辑维度与实际内存排布是两件事。下面说的块内部 `permute`，则是模型实现自己处理的维度顺序转换。

### 拆开一个 ConvNeXt V2 块

把一个块的输入记为 `x`，通道数为 `C`。先保留一份 `x`，作为稍后相加的捷径分支。另一条分支依次处理：

```text
x ────────────────────────────────────────────────┐
│                                                  │
└→ 7×7 深度卷积 → LayerNorm → Linear(C→4C)          │
                       → GELU → GRN → Linear(4C→C)  │
                       → DropPath ──────────────→ 相加 → 输出
```

1. **`7×7` 深度卷积（depthwise convolution）负责看邻域。** 普通卷积可以同时混合空间和通道；深度卷积则让每个通道使用自己的 `7×7` 核，先在该通道内汇总附近信息。它只需要约 `49C` 个核权重，忽略偏置；若使用输入输出均为 `C` 的普通 `7×7` 卷积，则需要 `49C²` 个。这里的邻域位于当前特征图上；深层特征图的一个格子已经对应原图中更大的范围，并非始终只看原图的 7×7 像素。
2. **LayerNorm 调整每个位置的通道数值尺度。** 可以把同一位置的 `C` 个数看成一个短向量，在通道维上求均值和方差，再标准化并进行可学习缩放、平移。它没有像 BatchNorm 那样使用整个微批的统计量，因此微批只有 2 张也能工作。
3. **通道 MLP 负责组合特征。** 在每个空间位置上，把长度 `C` 的向量送进 `C→4C→C` 的两层映射，中间有 GELU 非线性。这一步和你认识的 ANN 很像，但这套小 ANN 在所有空间位置共享参数，不是把整张特征图展平后全连接。GELU 是平滑的激活函数，让网络能够表达非线性关系。
4. **GRN 让通道参考整张特征图的相对响应。** 它是 V2 的关键组成部分，放在第一层 Linear 和 GELU 之后、第二层 Linear 之前。下面单独解释。
5. **残差连接把输入加回来。** 结果近似写成 `输出=x+F(x)`。网络可以在已有表示上学习增量，梯度也多了一条直接回传的路径，便于训练较深模型。训练时 DropPath 会随机丢弃部分残差分支；本项目设的 0.15 是按深度分配的最大丢弃率，并非所有块都固定丢弃 15%。验证时关闭随机丢弃。

一个容易看错的细节：本项目 Base 的默认 `conv_mlp=False`。因此 timm 的实际块内路径是 `NCHW→NHWC→LayerNorm/Linear/GRN→NCHW`。通道 Linear 在功能上类似位置共享的 `1×1` 卷积，但不能把本项目实际实现写成“一定调用了两个 `Conv2d(1×1)`”。

### GRN 的直观与简式

设某张图片的一张特征图为 `x_c(h,w)`。GRN 先对每个通道计算整张空间图的 L2 范数：

```text
g_c = sqrt(所有 h,w 上 x_c(h,w)^2 的和)
n_c = g_c / (所有通道 g 的平均值 + ε)
GRN(x)_c = x_c + γ_c · x_c · n_c + β_c
```

`g_c` 可以理解为这个通道的总体响应强度。`n_c` 比较它和其他通道的平均响应。最后由可学习的 `γ/β` 决定如何调整原特征。它为不同通道引入相对响应信息，而不是简单把所有通道强制变成同一个数，也不是对类别概率做归一化。`γ/β` 初始为 0，所以 GRN 初始表现为恒等映射，随后在训练中学习调整。

因此，虽然卷积首先利用局部邻域，带 GRN 的完整块也包含来自整张特征图的统计信息，不能把它描述成“整个网络始终只能看到局部”。GRN 的作用机制并不保证模型在这份数据上一定提高多少分。论文对 GRN 的提出与实验可以继续读 [ConvNeXt V2 原论文](https://arxiv.org/abs/2301.00808)。

本机 V2 的 `ls_init_value=None`，也就是没有使用 V1 块中可选的 LayerScale。不要把 LayerScale 的 `gamma` 和上面 GRN 自己的可学习缩放参数混成同一件事。

### 为什么最后得到 10 个数

最后一阶段是 `N×1024×24×24`，即每张图有 1024 张 24×24 的特征图。全局平均池化（GAP）对**每一个通道内部**的 576 个空间位置求平均，得到每图 1024 个数。它不会把 1024 个通道也一起平均掉。

随后做 LayerNorm，展平为 `N×1024`；训练时分类头 Dropout 以 0.2 的概率屏蔽部分输入特征，帮助减少对某些单一特征的依赖。验证时 Dropout 不随机屏蔽。最后的全连接层是你熟悉的 ANN：

```text
z = W f + b
f：长度 1024 的特征向量
W：10×1024 的权重矩阵
b：长度 10 的偏置
z：长度 10 的 logits
```

每个 `z_c` 是第 `c` 类的原始分数，取值可为任意实数。通过独立的 `sigmoid(z_c)=1/(1+exp(-z_c))`，才得到 0 到 1 之间的模型分数。例如 logits `[0,2,-2,...]` 对应约 `[0.5,0.881,0.119,...]`。十个数不需要相加等于 1：同一检查可能同时具有多个标签。

“十个独立 sigmoid”指输出变换与二分类损失逐类计算，不意味着疾病在现实中彼此独立，也不意味着十个分类器完全没有共享信息。它们共享前面整套主干网络；最终通过十行不同的权重读出不同类别的分数。

训练时把 logits 直接交给 `BCEWithLogitsLoss`，不要先 sigmoid 一次再传进去。验证与推理才把 logits 转成概率分数。本项目的这些分数用于比赛评估；尤其采用正样本加权后，不应把 0.8 直接解释成已经校准的“临床患病概率 80%”。GAP 加分类头输出的是整图分类分数，也不会自动给出病灶位置或诊断依据。

### 怎么在学习包里继续追代码

先读 `model_overnight.py` 的 `build_overnight_model()`，确认名称、10 类输出、平均池化及激活检查点设置；然后回到 `train_overnight.py` 看 `logits=model(images)` 怎样使用模型。激活检查点是在反向传播时重算一部分中间结果来节省显存，不等于保存到磁盘的训练断点，也不等于冻结网络。

本节架构与形状以本机 `timm==1.0.30` 的以下文件文本为核验基线：`models/convnext.py` 的 `convnextv2_base`、`ConvNeXt`、`ConvNeXtStage`、`ConvNeXtBlock`；`layers/mlp.py` 的 `GlobalResponseNormMlp`；`layers/grn.py` 的 `GlobalResponseNorm`；`layers/norm.py` 的 `LayerNorm2d`；`layers/classifier.py` 的 `NormMlpClassifierHead`。这些第三方实现由安装依赖提供，学习包不复制整套 timm。

线上继续阅读可用 [timm 官方 ConvNeXt 实现](https://github.com/huggingface/pytorch-image-models/blob/main/timm/models/convnext.py) 和 [作者官方 ConvNeXt V2 实现](https://github.com/facebookresearch/ConvNeXt-V2/blob/main/models/convnextv2.py)。链接的 `main` 分支将来可能变化；复现本项目应以 `requirements.txt` 固定版本和项目源码为准。
