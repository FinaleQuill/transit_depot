## 读懂代码时最常混淆的几个概念

| 两个容易混淆的词 | 在这个项目里怎样区别 |
| --- | --- |
| 输入 Normalize / LayerNorm / GRN | 输入 Normalize 使用固定 RGB 均值标准差处理像素；LayerNorm 调整某层特征向量的尺度；GRN 利用通道在整张特征图上的相对响应。它们作用的位置和统计量不同。 |
| 通道 / 类别 | 深层 1024 个通道是特征维度；最后 10 个输出才对应十类。一般不存在“第 7 个特征通道就是第 7 类”。 |
| logit / sigmoid 分数 / 二值标签 | logit 是任意实数；sigmoid 后落在 0～1；再与每类阈值比较才得到 0/1。训练损失收 logits，最终提交保留连续分数。 |
| 微批 / 有效批量 | 微批 2 是一次前后向看两张；累积 16 次后更新一次，常规完整窗口共看 32 张。它们不是 32 个完整 Study。 |
| 激活检查点 / 训练断点文件 | 前者反向时重算中间激活以省显存；后者在磁盘保存权重、优化器、进度等，以便中断后恢复。 |
| `model.train()` / `model.eval()` | 控制 Dropout、DropPath 等层的行为，不等于“允许/禁止计算梯度”的总开关。验证还用 `inference_mode()` 关闭梯度跟踪。 |
| EMA / 五折集成 | EMA 在训练时平滑一套模型的参数轨迹；五折集成在推理时平均多套模型的预测概率。不是同一种平均。 |
| `pos_weight` / Study 权重 | 前者逐类放大正标签的损失；后者逐图抵消 Study 视图数不同。两者作用在不同层面。 |
| 阈值 / AUC | 阈值决定某个点上的二值决策和 F1；AUC 衡量连续分数排序，不需要选一个固定阈值。 |

## 用纸笔检查自己是否读懂了

下面不需要运行任何脚本，先自己回答，再看参考答案。

1. 一张宽 1000、高 2000 的图片，等比例缩放到 768 方框，得到多大内容区？横向各补多少？
2. 为什么一个输出可以是 `[0.8,0.7,0.1,...]`，前两项相加大于 1 也没问题？
3. 一类正标签的预测 `p=0.1`，`pos_weight=20`。该项 BCE 的值和对 logit 的梯度各是多少？负标签是否也乘 20？
4. 两张属于同一 Study 的图对某类给出 0.2、0.8，验证时这个 Study 的分数是多少？如果另一 Study 只有一张图，算 Macro-AUC 时是否占更少权重？
5. 只修改最终阈值，能改变已经得到的 Macro-AUC 吗？能改变二值 F1 吗？
6. 默认微批 2、累积 16，epoch 尾部最后一个窗口只有 5 张图，分母还应该用 32 吗？
7. EMA 每读一张图片就更新一次吗？它的参数是否也参与 `backward()`？

参考答案：

1. 内容区宽 384、高 768；横向总共补 384，左右各 192。代码对整数尺寸做四舍五入，遇到奇数差值两侧最多相差一像素。
2. 本任务允许多个类别同时出现，每个输出是该类别自己的 sigmoid 分数，十项没有和为 1 的约束。
3. 未做类别/图像平均前，正项为 `-20 ln(0.1)≈46.05`，对该 logit 的梯度为 `20×(0.1-1)=-18`。负标签不乘这个正项权重，其损失为 `-ln(1-p)`。梯度下降沿负梯度更新，在其他量不变的局部直觉下会推高这个正样本的 logit。
4. 均值为 0.5；评分按 Study，而不是按图像视图数重复计分。单图 Study 仍是一行完整的 Study 预测。
5. 分数不变时 AUC 不变，二值 F1 可以改变。改变模型训练中的正权重则可能改变学到的分数和排序，是另一回事。
6. 应按实际 5 张图归一，避免让尾窗口梯度无意缩小。当前循环会计算实际 `window_images`。
7. EMA 在成功的优化器更新后通过 hook 更新；EMA 副本不接收反向梯度，验证读这份平滑参数。

## 下一步怎样看源码

先在编辑器搜索这条链：

```text
read_manifest → letterbox_rgb → OvernightImageDataset.__getitem__
→ collate_overnight → build_overnight_model
→ compute_loss_config / build_weighted_bce → train_epoch
→ evaluate → aggregate_study_predictions
→ _predict_model / _ensemble_phase → search_class_thresholds
```

对每一处只写下三个问题的答案：输入形状是什么、输出形状是什么、这里有没有可学习参数。然后再补两个问题：这里是否保留梯度、这里按图片还是 Study 计数。能把这五个问题答清楚，你已经能读懂这条 CNN 训练主线，而不只是记住网络名字。

学习副本只增加普通中文注释。制包验证使用 Python 标准库静态解析，比对注释前后的 AST（抽象语法树），确保算法语句和数值未改；没有导入项目、运行测试、创建模型、占用 GPU 或操作 tmux。原项目代码哈希也在制包前后复核。具体清单见包内 `PACKAGE_MANIFEST.json`。
